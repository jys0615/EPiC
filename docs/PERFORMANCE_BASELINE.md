# 📊 Performance Baseline

> **측정 환경**
> - 서버: Microsoft Azure (Korea Central)
> - URL: http://epic15.koreacentral.cloudapp.azure.com
> - 측정 도구: `scripts/measure_performance.sh`

## Phase 1 후 — Gzip + gpt-4o-mini + WebClient (2026-04-06)

### ⏱️ API 응답 시간

| 엔드포인트 | 1차 | 2차 | 3차 | **평균** |
|-----------|-----|-----|-----|---------|
| 커리큘럼 추천 (`gpt-4o-mini`) | 7.31s | 5.93s | 6.83s | **6.7s** |
| 챗봇 Q&A (`gpt-4o-mini`) | 2.61s | 2.22s | 3.41s | **2.7s** |

> GPT 모델 업그레이드(3.5-turbo → 4o-mini)로 응답 품질은 향상되었으나,
> 모델 자체 추론 시간 증가로 응답 속도는 소폭 느려짐.
> 캐싱 적용(Phase 2) 이후 캐시 히트 시 응답시간 대폭 감소 예정.

### 🌐 네트워크 현황

| 항목 | 상태 | 비고 |
|------|------|------|
| Gzip 압축 | **적용 완료** | 응답 크기 **40% 감소** |
| HTTPS | 미적용 | Phase 2 예정 |
| HTTP/2 | 미적용 | HTTPS 적용 후 활성화 예정 |
